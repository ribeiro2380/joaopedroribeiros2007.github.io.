# Portfólio — João Pedro Ribeiro Santos

Portfólio pessoal desenvolvido com HTML e CSS, pronto para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Crie ou entre na sua conta em https://github.com
2. Crie um repositório público chamado `joaopedroribeiros2007.github.io` (se esse nome estiver disponível; caso use outro nome, o endereço publicado será diferente).
3. Envie os arquivos `index.html` e `foto-perfil.jpg` para a raiz do repositório (mantenha os dois juntos).
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
7. Aguarde a publicação. O endereço do site aparecerá na seção GitHub Pages.

O conteúdo pode ser editado diretamente no arquivo `index.html`.
